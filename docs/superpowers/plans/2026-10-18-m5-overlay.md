# M5 Overlay ImGui — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Insert ou L3+R3 abrem um overlay ImGui dentro do jogo, navegável com o
comando e sem pausa, com desempenho ao vivo, as opções do ini, os contadores do AOT e o
log.

**Architecture:**
- **ImGui só no thread GPU, alimentado à mão.** O main thread (SDL) põe eventos numa fila;
  o `Composite` constrói o frame ImGui uma vez por frame apresentado e converte o
  `ImDrawData` numa estrutura simples, sem tipos ImGui (`VideoCore::OverlayDrawData`).
- **O `video_core` desenha, sem saber do ImGui.** Um `OverlayPass` no
  `renderer_vulkan/present/` grava, no command buffer do scheduler, um render pass LOAD
  sobre o `Frame::image` (depois do FSR). Pipeline, textura das fontes e buffers são dele;
  não há submissões próprias.
- **Lógica pura testável à parte:** estatísticas de frame, detetor de combinação,
  reescrita do ini, leitura de `/proc`, todos com testes `ctest`.

**Tech Stack:** C++20, Dear ImGui (núcleo, via CPM), Vulkan 1.1 com render passes, SDL3,
GLSL compilado pelo `video_core/host_shaders`.

**Spec:** `docs/superpowers/specs/2026-10-18-m5-overlay-design.md`.

## Global Constraints

- Linux x86-64. SDL3 ≥ 3.2.10. Vulkan carregado dinamicamente (`VK_NO_PROTOTYPES`), sem
  dynamic rendering.
- Dear ImGui numa release fixa, via `cpmfile.json` + `AddJsonPackage`, **sem**
  `imgui_impl_sdl3` nem `imgui_impl_vulkan`.
- O `video_core` não inclui headers do ImGui.
- O overlay não submete nada à fila por si.
- Fechado (e com o mini contador desligado, o defeito), custo zero mensurável no bench de
  combate. Aberto, ou com o mini contador ligado, < 0.3 ms por frame.
- Interface em inglês. Commits e docs sem caminhos pessoais. Testes nunca tocam em
  `~/.local/share/astralchain` nem em `~/.config/astralchain`.
- Chaves novas em `[overlay]`: `key = Insert`, `pad = l3+r3`, `fps_counter = false`.
- Branch `m5-overlay` a partir de `main` (`c9a7f1cf2`). Sem push.

## Review Focus

1. **Overlay aberto com o jogo a carregar ou numa cutscene** (frames apresentados em
   ritmo irregular, resize da janela, swapchain recriado). Esperado: sem crash, o overlay
   reaparece no frame seguinte. Teste: Task 6 (formato e tamanho mudam a meio).
2. **Fechar o overlay com um stick inclinado ou um botão premido.** Esperado: nada fica
   preso; o jogo vê tudo largado até nova pressão ou movimento. Teste: Task 7
   (`ReleaseAllOnClose`).
3. **Ini com edições à mão estranhas** (espaços à volta de `=`, chave duplicada, secção
   repetida, CRLF, comentários com `;` e `#`). Esperado: só o valor muda; tudo o resto
   igual byte a byte. Teste: Task 4.
4. **Combinação premida com o comando desligado a meio** (o Puck adormece). Esperado: o
   detetor esquece o comando removido e não dispara sozinho depois. Teste: Task 3.
5. **Save sem permissões de escrita ou disco cheio.** Esperado: mensagem no separador,
   ficheiro antigo intacto. Teste: Task 4 (diretório só de leitura).

### Task 6: `OverlayPass` no Vulkan

**Files:**
- Create: `runtime/video_core/overlay_draw_data.h` (se a Task 1 não o criou),
  `runtime/video_core/renderer_vulkan/present/overlay_pass.h/.cpp`,

- Modify: `runtime/video_core/renderer_base.h`,
  `runtime/video_core/renderer_vulkan/renderer_vulkan.h/.cpp`,
  `runtime/video_core/host_shaders/CMakeLists.txt`, `runtime/video_core/CMakeLists.txt`

**Interfaces:**
- Produces, em `RendererBase`:
```cpp
class FrameOverlay {
public:
    virtual ~FrameOverlay() = default;
    virtual const OverlayFontAtlas& Font() = 0;            // chamado uma vez
    virtual OverlayDrawData Build(float width, float height) = 0; // thread GPU, por frame
};
void SetFrameOverlay(std::shared_ptr<FrameOverlay> overlay); // qualquer thread, antes ou durante
```
- `RendererVulkan::Composite`: depois de `blit_swapchain.DrawToFrame(...)` e antes de
  `scheduler.Flush(*frame->render_ready)`, se há overlay: `Build(frame->width,
  frame->height)`; se não vazio, `overlay_pass.Record(scheduler, *frame, std::move(data))`.
- `OverlayPass`: render pass `CreateWrappedRenderPass(device, format, VK_IMAGE_LAYOUT_GENERAL)`
  (LOAD), framebuffer próprio por `Frame` (recriado se o `VkImageView` ou o tamanho
  mudar), pipeline com blending alfa e scissor dinâmico, push constant com escala e
  translação, textura das fontes carregada uma vez com cópia gravada no scheduler,
  buffers de vértices e índices num anel host-visible em que cada slot guarda o tick do
  scheduler onde foi usado e só é reutilizado depois de `scheduler.IsFree(tick)`.
- Só o `blit_swapchain`; screenshots e applets sem overlay.

- [ ] **Step 1:** opção de linha de comando `--overlay-test` no frontend (escondida) que
  instala um `FrameOverlay` de teste com um retângulo sólido e o texto da fonte.
- [ ] **Step 2:** `acre.py run -- --overlay-test` com o jogo: o retângulo aparece por
  cima do jogo, nítido com `resolution_scale` 1 e 2; redimensionar a janela e alternar
