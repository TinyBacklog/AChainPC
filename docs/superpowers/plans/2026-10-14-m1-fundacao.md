# M1 Fundação — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ter o AstralChainRe como repositório próprio. O runtime do suyu entra por
vendoring com histórico, há um build limpo do runtime e de um frontend mínimo
(`astralchain`), e os testes do lifter correm verdes em `ctest`.

**Architecture:** Um clone temporário do `suyu-v0.0.4` (branch `aot-recomp`) é filtrado
com `git filter-repo` e fundido no AstralChainRe. A raiz do CMake do suyu passa a ser a
raiz do projeto, `src/` passa a `runtime/` e `src/suyu_cmd/` passa a `frontend/`. Os
módulos excluídos pela spec saem do histórico. Os submódulos não usados saem também.

**Tech Stack:** CMake 4.4 + Ninja, GCC 16 (o compilador com que o export atual foi
construído) ou clang 22, CPM com cache local, SDL3 e Vulkan, Python 3 (só para a
importação), `git filter-repo`.

**Spec:** `docs/superpowers/specs/2026-10-14-astralchainre-design.md`

## Global Constraints

- Licença GPL-2.0-or-later.
- Linux x86_64 apenas.
- Nada derivado do dump do jogo entra no git. `work/` está no `.gitignore`.
- O suyu original (`<suyu-v0.0.4>`) não é modificado.
- Commits com o autor `kadinho <kadinho@protonmail.com>` (git config local), sem
  `Co-Authored-By` e nunca com push.
- Excluídos da spec: `suyu`, `yuzu`, `qt_common`, `yuzu_cmd`, `android`,
  `libretro_core`, `dedicated_room`, `yuzu_room_standalone`, `web_service`, `tests`.
- `nintendo_library` e `network` ficam enquanto o `core` depender deles. A spec pede
  `network` desligado por defeito, mas isso é trabalho de M2.

### Desvio da spec (layout)

O CMake do suyu usa `CMAKE_SOURCE_DIR` para `externals/`, `.cache/cpm` e
`cpmfile.json`. Por isso, `CMakeLists.txt`, `CMakeModules/`, `cpmfile.json` e
`externals/` ficam **na raiz** do repositório, e não em `runtime/`. O `runtime/`
contém os antigos módulos de `src/`. A spec é atualizada na Task 1.

## Review Focus

1. **Configurar sem o cache do CPM do suyu.** Esperado: o CMake descarrega as
   dependências e não falha com um path absoluto do suyu. A Task 3 verifica que não há
   nenhum `suyu-v0.0.4` em ficheiros versionados.
2. **Histórico preservado.** `git log --follow runtime/core/arm/recomp/arm_recomp.cpp`
   mostra os commits do suyu, e `git log -- runtime/core/core.cpp` mostra mais de um
   commit (Task 2).
3. **O build do `astralchain` sem export não pode exigir `ASTRALCHAIN_RECOMP_DIR`.**
   O binário deve compilar e ligar só com o JIT (Task 4).
4. **Testes do lifter com paths absolutos.** O `run-tests.sh` original usa
   `/var/www/...` e `/tmp/claude-...`. Os testes em `ctest` não podem depender de paths
   fora de `${CMAKE_BINARY_DIR}` (Task 5).
5. **Testes de AES/SHA precisam de libcrypto.** Se o OpenSSL faltar, o CMake deve dar
   erro claro em vez de os testes falharem com mensagens de linker (Task 5).

**Interfaces:**
- Consumes: `runtime/core/recompiler/arm64_to_c.h` (incluído pelos geradores com

- Produces: `ctest --test-dir build -L lifter`.

Cada `test_<t>.cpp` é um gerador. Compila-se para o host e, quando corre, imprime um
programa C que testa a tradução. Esse C compila-se e corre, e o teste passa com exit 0.
`test_exclusive.cpp` é diferente: corre diretamente.

- [ ] **Step 1: Escrever `tools/tests/run_lifter_test.cmake`**

```cmake
# Runs one lifter test: generator -> C source -> native binary -> exit code.
# Inputs: GEN (generator executable), CC, OUT_DIR, NAME, LIBS (;-list)
execute_process(COMMAND "${GEN}" OUTPUT_FILE "${OUT_DIR}/${NAME}.c"
                RESULT_VARIABLE r ERROR_VARIABLE e)
if (NOT r EQUAL 0)
    message(FATAL_ERROR "${NAME}: generator failed (${r}): ${e}")
endif()
execute_process(COMMAND "${CC}" -std=c11 -O2 -fsanitize=undefined -fsanitize-trap=all
                        "${OUT_DIR}/${NAME}.c" -o "${OUT_DIR}/${NAME}.bin" ${LIBS}
                RESULT_VARIABLE r ERROR_VARIABLE e)
if (NOT r EQUAL 0)
    message(FATAL_ERROR "${NAME}: generated C failed to compile: ${e}")
endif()
execute_process(COMMAND "${OUT_DIR}/${NAME}.bin" RESULT_VARIABLE r
                OUTPUT_VARIABLE o ERROR_VARIABLE e TIMEOUT 300)
message(STATUS "${NAME}: ${o}")
if (NOT r EQUAL 0)
    message(FATAL_ERROR "${NAME}: test failed (${r}): ${o}${e}")
endif()
```

- [ ] **Step 2: Escrever `tools/tests/CMakeLists.txt`**

```cmake
find_package(OpenSSL COMPONENTS Crypto)
if (NOT OpenSSL_Crypto_FOUND)
    message(FATAL_ERROR "Lifter tests need libcrypto (openssl-devel). "
                        "Install it or configure with -DACRE_TESTS=OFF.")
endif()

set(_lifter_tests adc bitfields extract fp simd crc32 recip aes sha1 sha256 satsimd chain)
set(_lifter_out "${CMAKE_CURRENT_BINARY_DIR}/out")
file(MAKE_DIRECTORY "${_lifter_out}")

foreach(t IN LISTS _lifter_tests)
    add_executable(lifter_gen_${t} test_${t}.cpp)
    target_include_directories(lifter_gen_${t} PRIVATE ${PROJECT_SOURCE_DIR}/runtime)
    target_compile_features(lifter_gen_${t} PRIVATE cxx_std_20)
    add_test(NAME lifter_${t}
             COMMAND ${CMAKE_COMMAND}
                     -DGEN=$<TARGET_FILE:lifter_gen_${t}> -DCC=${CMAKE_C_COMPILER}
                     -DOUT_DIR=${_lifter_out} -DNAME=${t}
                     "-DLIBS=-lcrypto;-lm"
                     -P ${CMAKE_CURRENT_SOURCE_DIR}/run_lifter_test.cmake)
    set_tests_properties(lifter_${t} PROPERTIES LABELS lifter TIMEOUT 600)
endforeach()

add_executable(lifter_exclusive test_exclusive.cpp)
target_include_directories(lifter_exclusive PRIVATE ${PROJECT_SOURCE_DIR}/runtime)
target_compile_features(lifter_exclusive PRIVATE cxx_std_20)
add_test(NAME lifter_exclusive COMMAND lifter_exclusive)
set_tests_properties(lifter_exclusive PROPERTIES LABELS lifter)
```
